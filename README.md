# Money's the Matter

Official website for the Money's the Matter podcast.

## Structure

```
css/         Shared styles
images/      Logos, artwork, episode images
episodes/    Individual episode pages
templates/   Master HTML templates
```

## Publishing Workflow

1. Copy `templates/episode-template.html`
2. Create a new folder in `episodes/`
3. Rename the file to `index.html`
4. Replace placeholders
5. Preview with Live Server
6. Commit
7. Push to GitHub
